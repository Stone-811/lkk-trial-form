# 體驗課電子表單＋六類高風險標記｜工程交接包 v2（2026-11-10）

- 提供：練健康 教育訓練部（宇劭）
- 整理：Claude

## 這是什麼

練健康的體驗課現在用紙本《體適能運動諮詢單》，再到 SurveyCake 留一次資料。要改成**現場平板填的電子表單**。學員和教練一起填，學員手寫簽名，送出後自動做三件事：

1. **存檔**：答案進總表（一人一列），填好的表單存成 PDF（含簽名）
2. **判定六類高風險標記**：骨折、跌倒、心血管、暈厥、癌症、術後，另加「其他」。規則是固定的 if/else，不需要 AI
3. **開課表**：依標記，提示課表上哪些動作禁忌、要調整、建議優先排

**這包要交給你的是規格，不是程式。** 05 的網頁是 Claude 做的試用版，只能在 claude.ai 裡、用宇劭連好的 Google 帳號送出，不能直接拿去上線。判定要寫進你們的系統（11/10 宇劭定）。

```
 ▼      ▼              ▼                ▼
存答案  存 PDF       判定六類標記      開課表
(一人一列) (含簽名)   (02 規格)        (32 堂骨架＋動作風險對照表)
                       │
        ┌──────────────┼──────────────┐
        ▼              ▼              ▼
      有標記        資料未齊        其他待確認
   通知教練／店長／   通知補填、      店長填原因、
   教訓部，課表顯示   補完自動重算    教訓部確認
   標記與原因
```

## 要特別注意的地方

1. **OSTAi／MOSTAi 一定要用整數寫法**，浮點誤差會判錯人，見 02 的 F3。
2. **「資料未齊」不能顯示成「無風險」**，見 02 第 1 節。
3. **以 02 規格為準**。Google 試算表 v28 的公式已跟規格一致，但它用 V 勾選，分不出「沒填」和「否」（02 第 7 節）。
4. **骨折以外五類的動作標籤是暫定的**，畫面要標「暫定」，見 03。
