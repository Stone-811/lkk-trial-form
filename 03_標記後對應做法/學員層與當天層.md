# 六類標記｜學員層與當天層

- 來源：宇劭 Notion《六類高風險標記｜標記與對應做法（學員／當天／動作三層）_v1_20261104》（草稿）
- 標「定」的是宇劭 11/4 前後拍板的；沒標的是照指引或 10/26 初稿整理的，**待確認**
- 判定規則上線第一版只顯示「標記＋觸發原因」；本頁的注意事項審定後再接進系統（11/3 定）

## 共用

- 標記在體驗課產生；PAR-Q+ 之後不重填（定）
- 標記不亂拿掉，存「標記日期＋觸發條件」（定）
- 觸發標記的數值要追蹤、跟學員講解趨勢（定）
  - OSTAi 不當成果：它只看體重和年齡
  - 血壓是安全監控，不是訓練目標
- 重測：五次坐到站在標準內者，每 2–4 堂試一次單腳坐到站（定）
- 同時有兩類以上標記：每個動作取最嚴，條件全部照做
- 標記後的人員流程：教練當堂照注意事項帶 → 下班前告知店長 → 店長登錄，確認之後排到的教練都知道

## 骨折

**學員層**
- 教練站近學員
- 用 Teriparatide 初期可能頭暈：換姿勢放慢（骨鬆指引三-2）
- 用雙磷酸鹽類：避免長時間低頭或腹壓大的趴姿；大腿前外側深層隱痛 → 轉介（三-2）
- 紅旗：出現下列任一 → 停止、就醫（九-2）
  - 背部突然深層銳痛
  - 髖或鼠蹊負重痛
  - 下肢麻痛或大小便失禁
  - 任何跌倒
- 平衡訓練量照 HBA 2024（定）
  - 每週至少 3 次、累積至少 3 小時含挑戰性平衡的運動；阻力和衝擊的時間可以算進去
  - 強度用 5 分平衡費力量表，從 3 分練到 4 分
  - 一對一每週 1–2 堂達不到 3 小時，用居家作業補（推論）

**當天層**：問有沒有新的背痛、最近有沒有跌倒

**動作層原則**（逐個動作見動作風險對照表）
- **禁忌**：
  - 脊椎屈曲、主動軀幹旋轉（定）。其中飛機式算旋轉＝禁忌；戰術起身、捷克起身不算；世界最好的伸展只做拿掉轉胸那一步的退階版
  - 深跳、落下跳、硬落地、跳遠（定）
- **要調整**：
  - 槓鈴軸向負重：先能維持中立位，從輕開始
  - 中度以上衝擊跳躍
  - 單腳動態、過肩負重、前傾負重
- **建議**：
  - 多關節軸向阻力、背伸肌、平衡
  - 小跳、跳上低箱（定）
- 有脊椎骨折或 T ≤ −2.5 → 跳躍只做低衝擊（骨鬆指引六 FITT）

## 跌倒

**學員層**
- 上課時教練站在易倒側，或學員靠在牆壁附近；扶手只有居家作業才一定要（定）
- 場地淨空；倒退走、轉頭走先確認後方
- 注意會讓人頭暈或嗜睡的藥（鎮靜安眠、抗憂鬱、降壓、利尿等）、剛換藥
- 居家作業只選獨自做也安全的動作

**當天層**：問今天會不會暈、最近有沒有跌倒、有沒有換藥

**動作層原則**
- **禁忌**：跟骨折類同一批高衝擊跳躍；大幅度推拉擾動；沒有安全夾的跑步機
- **要調整**：
  - 地面起身類：從較高的平台倒序練
  - 其他跳躍：先通過單腳站、在牆邊做
- **建議**：平衡進階（縮小支撐面、移動重心、減少手的支撐）、坐到站類、登階、下肢阻力

## 心血管

**學員層**
- 出力吐氣、不憋氣
- 阻力強度 ≤ 80% 1RM、不做到力竭（ESC 2020 §4.2.3；暫定）
- 有吃 β 阻斷劑：最大心率＝164 − 0.7 × 年齡（Brawner 2004）
  - 用儲備心率法算目標心率，同時用 RPE 或說話測試對照
  - 有服藥狀態下測的最大心率，就用實測值
- 暖身與緩和各 5–10 分鐘，不要突然停
- 胸痛、胸悶、不成比例的喘、頭暈、心悸 → 立即停止

**當天層**
- 有心血管標記的人每堂量血壓（定）
- 血壓 ≥ 180/110：當天不練；160–179／100–109：只做低中強度（定）
- 先量血壓再測握力；≥ 180/110 當天不測握力，除非醫師允許；測的時候提醒吐氣（定）

**動作層原則**
- **要調整**：
  - 中高負荷、超過 5 秒的等長撐
  - 高強度間歇、跳躍、爆發：只給控制穩定且醫師同意者
- **建議**：
  - 中等重量、下數多一點的器械與滑輪
  - 輕負荷有氧（推雪橇、行走）
- 不做 1RM 測試，用 5RM 估算（暫定）

## 暈厥

不分紅、黃兩層，有標記就照下面做（定）

**學員層**
- 躺或坐 → 站、彎腰 → 站直都要慢，站直後停一下再走
- 不要久站不動，組間動動腳；練完一定主動緩和 5–10 分鐘
- 出力吐氣、不憋氣
- 教反壓動作（交叉腿夾緊、握拳、雙臂互拉）；場地避免悶熱

**當天層**
- 問今天有沒有吃飯、喝水，最近有沒有換降壓或利尿藥
- 用胰島素或磺醯尿素類者：運動前血糖 < 90 mg/dL，先補碳水

**動作層原則**
- **要調整**：地面起身類；彎腰後回到直立的動作（硬舉類，回到直立後停一下）
- **建議**：坐姿器械、下肢與核心阻力（肌肉幫浦）

## 癌症

**學員層**
- 第一堂確認子族群：骨轉移（病灶位置）、PICC／port、造口、淋巴水腫、神經病變、血球低、幹細胞移植
- 每位學員要能聯絡到治療團隊至少一人
- 有骨轉移的學員由店長分配教練（定）
- 化療後第 3–5 天最累，排課要避開或降強度
- 淋巴水腫：所有上肢負重從輕重量開始、慢慢加、有人監督
- 造口、上腔靜脈症候群：不憋氣，改中等重量

**當天層**：發燒、感染、出血、新的骨頭痛 → 當天不練並轉介

**動作層原則（依子族群）**
- 骨轉移：
  - 套骨折第二層；病灶區的快速動作或負重末端動作禁忌
  - 病灶肢體低負荷起步、慢慢加（暫定，採 Campbell 2022）
- 血小板低：接觸、易跌易撞的動作禁忌
- 嗜中性球低：高強度禁忌
- 神經病變：器械優先、跑步機要有扶手、加平衡訓練
- 不做 1RM

## 術後／傷後

**學員層**
- 醫師或治療師寫的限制最優先（負重、角度、動作、重量）
- 確認是否還在物理治療中、治療師是否同意開始健身
- 人工髖：醫囑有寫預防姿勢，才限制深屈髖＋內旋＋內收（暫定）
- 開腹、開放式切口疝修補後 4 週內不憋氣用力；腹股溝疝氣術後不另設週數限制（暫定）
- 紅旗：出現下列任一 → 停止並轉介
  - 小腿腫痛
  - 胸痛、喘
  - 傷口紅腫熱痛或化膿
  - 人工髖那隻腳變短、轉向
  - 大小便或會陰感覺改變

**當天層**：問疼痛、腫脹、隔天痠痛有沒有變嚴重；變嚴重就退一級

**動作層原則**
- **禁忌**：醫囑寫的；人工髖膝的跑跳與接觸性運動（Vogel 2011 表 5、6）
- **要調整**：
  - 手術部位：在醫囑範圍內慢慢加
  - ACL 跳躍：等治療師核可（回跑步 LSI > 80%、增強式 > 90%）
  - 腰椎手術後醫囑沒寫時：前 2 週不做彎腰、扭轉類（暫定）
- 非手術部位照常練

## 還沒定

1. 骨折第二層（脊椎骨折族群）要不要加門檻：T ≤ −3.0、多處骨折、醫療許可
2. 相撲硬舉的替代動作
3. 追蹤圖要畫哪幾項
