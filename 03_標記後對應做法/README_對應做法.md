# 03 標記後的對應做法

標記算出來之後，教練要照著做的事分三層。資訊放在會變的那一層；每個動作都一樣的事，不標在動作上。

| 層 | 什麼時候用 | 檔案 |
|---|---|---|
| 學員層 | 有標記後，每堂都適用（注意事項、紅旗） | `學員層與當天層.md` |
| 當天層 | 每堂上課前量測／詢問，決定今天練不練、練多重 | `學員層與當天層.md`；血壓門檻也寫在 02 第 6 節 |
| 動作層 | 排課表時，逐個動作標「禁忌／要調整／建議」，空白＝照常做 | `動作風險對照表_六類.csv` |

另附 `32堂骨架.csv`：體驗課後前 32 堂的預設課表（A／B 兩版），系統要能自動帶出課表時會用到。

## 動作風險對照表怎麼用（動作層）

`動作風險對照表_六類.csv`：121 個動作 × 六類，跟公版課表 v28「動作風險對照表」分頁同一份資料。

| 欄位 | 意思 |
|---|---|
| 動作名稱 | 跟動作資料庫的名稱一致（中英對照） |
| 比對鍵 | 動作名稱去掉空白、換行、轉小寫，用來比對教練打的動作 |
| 骨折…術後（6 欄） | 禁忌（不排）／要調整（可以排，照條件欄改）／建議（優先排）／空白（照常做） |
| 骨折條件…術後條件（6 欄） | 要調整時怎麼改 |
| 替代動作（骨折） | 骨折禁忌時改做什麼 |
| 理由、出處（骨折） | 骨折類的依據 |

**套用規則**（公版課表 v24 起的做法，11/4 定）：
1. 只看學員**有的**標記類別
2. 同一個動作在幾類的標籤不同時，**取最嚴**：禁忌 ＞ 要調整 ＞ 建議 ＞ 照常
3. 條件欄：把學員每一類「要調整」的條件全部列出來，例如「骨折：起始位墊高到不產生脊椎屈曲；暈厥：回到直立後停一下再動」
4. 骨折禁忌、而且有替代動作時，顯示「改做：○○」
5. 每堂課頂端彙總：禁忌幾個（須更換）、要調整幾個；有心血管或暈厥標記時加「需量血壓」

**資料的確定程度**：
- 骨折類：10/31 原表換算，已審。
- 其他五類（跌倒、心血管、暈厥、癌症、術後）：依動作名稱推論的暫定標籤，**還沒逐類審**，畫面上要標「暫定」。
- 各類筆數（禁忌／要調整／建議）：

| 類別 | 禁忌 | 要調整 | 建議 |
|---|---|---|---|
| 骨折 | 20 | 27 | 74 |
| 跌倒 | 4 | 8 | 24 |
| 心血管 | 0 | 20 | 6 |
| 暈厥 | 0 | 19 | 20 |
| 癌症 | 0 | 39 | 15 |
| 術後 | 0 | 26 | 0 |

## 32 堂骨架怎麼用

`32堂骨架.csv`：課表編號 1–40，每份 7 列（熱身、配對 A 兩個、配對 B 兩個、配對 C 兩個）。

- **B 版**（給比較弱的學員）：第 n 堂＝編號 n，用 1–32
- **A 版**（給中等程度的學員）：第 n 堂＝編號 n＋8，用 9–40
- **建議版本**：五次坐到站 ≥ 12 秒 → B 版；< 12 秒 → A 版，但要先確認學員能不扶東西自己上下地板（題目 K24 會先顯示這個建議）。握力要不要納入還沒定
- **目前進度**：編號 1–40 都已排好（11/10），11/13 定案前還會補六類加量備註
- **劑量原則**：阻力動作 3–5 下 × 3–5 組；RPE 每 4 份往上一級，第 15 份起 RPE 8、每組 4 下，之後維持次數、加重量；不加爆發力動作，深蹲（前抱式）與硬舉（六角槓）13–40 不換動作一路加重（11/10 定）
- 骨架只是預設值，系統上要讓教練能直接改

骨架裡的動作一樣要套上面的動作層規則：例如學員有骨折標記，骨架帶出的禁忌動作要提示更換。
